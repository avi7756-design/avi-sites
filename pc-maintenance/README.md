# AviPC Care — ערכת תחזוקה ובקרה אוטומטית למחשב

ערכה שמותקנת פעם אחת ומאז עובדת לבד ברקע: בודקת את בריאות המחשב כל 4 שעות,
מנקה אותו בבטחה פעם בשבוע, ומציגה הכול בדשבורד עברי ברור — כולל התראה מוקדמת
לפני שהמחשב נתקע.

## התקנה (פעם אחת, דקה אחת)

פתח **PowerShell** (התחל ← הקלד PowerShell ← Enter) והדבק:

```powershell
irm https://raw.githubusercontent.com/avi7756-design/avi-sites/main/pc-maintenance/Setup.ps1 | iex
```

זהו. בסיום נפתח הדשבורד, ועל שולחן העבודה מופיע קיצור **AviPC Dashboard**.

## מה רץ ברקע אחרי ההתקנה

| משימה | תדירות | מה היא עושה |
|---|---|---|
| AviPC-Care Health | כל 4 שעות | אוספת נתוני מעבד/זיכרון/דיסק/תוכנות, מחשבת ציון בריאות, מעדכנת את הדשבורד, ומקפיצה חלון אזהרה אם זוהתה בעיה קריטית (למשל דיסק כמעט מלא) — **לפני** שהמחשב נתקע |
| AviPC-Care Maintenance | יום ראשון 09:00 | ניקוי בטוח: קבצים זמניים ישנים, מטמון עדכוני Windows, מטמון Delivery Optimization. רושמת יומן פעולה מלא |

## מה הערכה לעולם לא נוגעת בו

מסמכים, שולחן עבודה, תמונות, הורדות, OneDrive, מיילים, דפדפנים, סיסמאות —
**שום קובץ אישי לא נמחק ולא מוזז**. הניקוי מוגבל לתיקיות זמניות ומטמונים
ש-Windows יודע לבנות מחדש. סל המיחזור מתרוקן רק אם מבקשים במפורש
(`Maintenance.ps1 -IncludeRecycleBin`).

## הדשבורד

פתיחה: לחיצה כפולה על הקיצור בשולחן העבודה. מציג:

- **ציון בריאות 0–100** ותמונת מצב במבט אחד
- **התראות** עם הסבר בעברית והמלצה מעשית לכל בעיה
- **מדדים חיים**: מעבד, זיכרון, מקום פנוי בדיסק, זמן מאז הפעלה מחדש
- **גרף מגמה** של העומס לאורך הימים האחרונים
- **טבלת התוכנות** שצורכות הכי הרבה זיכרון ומעבד — כדי לדעת בדיוק מי מאט

הדשבורד מתעדכן בכל בדיקה; רענון הדף (F5) מציג את הנתונים האחרונים.

## הרצה ידנית (לא חובה)

```powershell
# בדיקת בריאות עכשיו
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\AviPC-Care\HealthCheck.ps1"

# ניקוי עכשיו (הוסף -Deep פעם בחודש לניקוי עמוק, דורש הרשאות מנהל)
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\AviPC-Care\Maintenance.ps1"
```

## הסרה

```powershell
schtasks /Delete /F /TN "AviPC-Care Health"
schtasks /Delete /F /TN "AviPC-Care Maintenance"
Remove-Item "$env:USERPROFILE\AviPC-Care" -Recurse -Force
```

## קבצים בערכה

- `Setup.ps1` — התקנה חד-פעמית (משימות רקע + קיצור דרך)
- `HealthCheck.ps1` — איסוף נתונים, חישוב ציון, התראות
- `Maintenance.ps1` — ניקוי בטוח + יומן פעולה
- `dashboard.html` — הדשבורד (נתונים נטענים מ-`health-data.js` שנוצר מקומית)
- `REPORT.md` — דוח השיפורים המלא וההמלצות
